## Проект Proxiya

### Общее описание

Proxiya - это удобная и современная UI-надстройка над mitmproxy, позволяющая работать с проксями в Desktop-режиме

### Основные возможности

Для версии v1.0:

- Просмотр запросов и ответов, перехватываемых через mitmproxy
- Создание, конфигурирование, запуск отдельных инстансов mitmproxy с заданными настройками
- Фильтрация перехватываемых запросов
- Модификация запросов и ответов
- Система сохраняемых пресетов для разных аспектов - конфигурации проксей, наборы фильтров, цепочки модификаторов
- Гибкий и настраиваемый, при этом минималистичеый UI-интерфейс

### Архитектура

- Оконное Desktop-приложение на Compose Multiplatform (UI) - визуал для пользователя
- Приложение-контроллер проксей (уровень абстракции над mitmproxy, а потенциально и над любым прокси-тулом) - менеджерит интансы проксей mitmproxy, пропускает через себя запросы-ответы
- Аддон для mitmproxy, запускаемый для инстанса mitmproxy и взаимодействующий с контроллером

#### Коммуникация

- UI общается с контроллером по gRPC
- Контроллер общается с запущенной проксей посредством аддона - по gRPC
- Единый набор протобуф-файлов для общих сущностей - HTTP-запрос, HTTP-ответ
- Связь UI <-> Контроллер разделена на 2 непересекающихся канала:
    - канал данных (mitmproxy ->> controller <<->> ui) - перехваченные запросы-ответы
    - канал управления и конфигурирования (UI <<->> mitmproxy) - применение фильтров, настроек, модификаторов, операции с инстансами проксей, оповещение на UI о статусах
